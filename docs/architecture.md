# 项目架构

本项目基于 i.MX6ULL 和 Linux 4.1.15，使用 Qt 5.15.18 实现触摸式车载终端演示。当前功能包括音乐播放、触摸交互、传感器数据显示、网络天气查询和时钟显示。项目定位为嵌入式功能验证平台，不包含 GPS、视频播放或实车控制功能。

## 软件层次

| 层次 | 组成 | 职责 |
| --- | --- | --- |
| 硬件 | LCD、FT5426、WM8960、AP3216C、ICM20608、USB Wi-Fi | 显示、输入、音频、传感器及无线通信 |
| 内核 | BSP 驱动、项目传感器驱动、替换后的触摸驱动、Realtek 驱动 | 管理硬件并提供用户空间接口 |
| 系统环境 | Buildroot、BusyBox、ALSA、wpa_supplicant、curl/OpenSSL、证书 | 提供运行库、网络连接、时间同步和 HTTPS 能力 |
| 应用 | Qt Widgets、音频播放逻辑、传感器读取、天气请求 | 展示数据并响应用户触摸操作 |

## 显示和触摸

Qt 使用 linuxfb 平台插件将界面绘制到 framebuffer，本项目使用 /dev/fb0。FT5426 将触摸动作上报到 Linux input 子系统，Qt 输入插件据此触发控件事件。

当前开发环境使用 /dev/input/event1。事件节点编号不是硬件的永久标识，改变内核或设备注册顺序后需要重新确认。

## 音乐播放

应用读取本地音乐文件，经音频播放逻辑向 ALSA 提交 PCM 数据，由内核音频驱动及 WM8960 输出到喇叭。界面支持曲目切换、播放控制、进度定位和百分比音量操作。

当前程序的播放能力以实际实现为准，不应将本地 WAV 播放描述为支持所有压缩音频格式。项目已验证使用 16 位、48 kHz、双声道 PCM WAV 的播放路径。

界面百分比与声卡寄存器原始数值不是同一种量纲；音量控制需要通过 ALSA 的音量范围和实际听感进行映射。

## 传感器数据

AP3216C 经 I²C 驱动提供红外、环境光和接近数据；ICM20608 经 SPI 驱动提供加速度、角速度及芯片内部温度数据。Qt 通过字符设备读取，按驱动与应用约定解析并更新页面。

传感器采样和耗时操作应与界面刷新解耦，避免阻塞主线程。设备异常时界面应显示不可用或过期状态，不能把旧值长期当作最新值。

AP3216C 不测量温湿度；ICM20608 芯片内部温度不能代替车内气温。

## 网络、天气和时钟

Realtek 驱动提供无线接口，wpa_supplicant 完成热点认证，DHCP 获取网络地址及相关参数，路由和 DNS 支持外部服务访问。

当前天气实现通过异步启动 curl 请求 Open-Meteo HTTPS 接口，并解析 JSON 数据。curl 使用 libcurl、OpenSSL 和 CA 证书完成请求及证书验证。该实现不依赖 Qt Network 发起天气请求。

天气页面显示网络气象数据，传感器页面显示板载测量数据，两者来源不同。天气请求失败时保留上次成功数据并提示失败，不代表数据仍然实时。

应用读取系统时间显示时钟。NTP 负责联网校时，RTC 可用于保存和恢复时间。启动时钟恢复、联网同步和断网运行属于系统配置工作，不应认为绘制一个时钟控件就自动完成了校时。

## 工作范围

项目复用了 BSP 内核已有的显示和声卡驱动，通过设备树完成板级适配；传感器、触摸和无线驱动的集成范围见 drivers/README.md。第三方驱动来源和原有许可应保留。
